Max's Personal Finance Dashboard

The application requires no setup whatsoever. Simply double-click the HTML file to load the program in your browser.

The dashboard allows you to input (and delete) transactions, where you may record your income and expenses over a given month. In real time, the dashboard will calculate your: total monthly income, total monthly expenses, net balance, and savings rate.

In addition, the dashboard displays a graph of your income, expenses, and balance so you can visualize them side by side.
